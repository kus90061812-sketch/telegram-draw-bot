# SPORT NOW v13.3 — Unlimited Picks / No Combo

변경:
- 픽 개수 제한 완전 제거
- KBO / NPB / MLB / 축구 / 농구 모두 개수 상한 없음
- 하루 전체 픽 개수 제한 없음
- PRIME SCORE 55 기준은 그대로 유지
- 이미 게시한 동일 경기 중복 방지는 그대로 유지
- FINAL COMBO / 2폴 조합픽 게시 기능 제거
- 개별 PRIME PICK 분석글만 게시

중요:
픽 수 제한이 없으므로 오전/오후/야간에 뒤늦게 분석 구간에 들어오는 경기도
그 시점에 조건을 충족하면 게시될 수 있습니다.

기존:
- Sportradar 야구 라인업
- NPB Sportradar 일정
- 한글 팀명
- 오마카세 버튼
- 결과/적중 기록
유지.
